# 双语精读译本 · 文风卡

- 准确优先，不增译、不省略，不进行文学化改写。
- 使用简体中文；句法自然，但保留作者论证结构和语气强度。
- 术语必须遵守本次构建绑定的冻结快照。
- 人名保留英文；机构、公司、出版物与产品名首次出现时可保留英文，后续保持一致。
- 地名采用通行中文译名；机构名、出版物名和英文书目信息中的地名不拆译，例如 Boston Consulting Group、New York Times 和出版地字段。
- 年代统一写作“20 世纪 80 年代”；跨年代范围写作“20 世纪 70—80 年代”。
- 单独出现的世纪统一用阿拉伯数字与空格，如“16 世纪”“19 世纪”；`mid-2000s` 写作“2000 年代中期”，不弱化为“21 世纪初”。
- 汉字与相邻拉丁字母之间保留一个半角空格，Markdown 标记、网址和英文专名内部不拆分。
- 保留数字、链接和 Markdown 结构；行内脚注号统一写为 `[n]`，避免数字紧贴汉字。
- 只返回请求指定的段落 ID 与中文译文，不回抄英文原文。
